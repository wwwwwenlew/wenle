# 工业园区人员定位安全监管三维大屏

这是一个脱敏作品集 Demo，用于展示 B/S 可视化大屏、Three.js 三维交互、人员定位报警和楼层钻取能力。

## 技术栈

- Vue 3
- TypeScript
- Three.js
- ECharts
- GSAP
- Vite

## 已实现交互

- 工业园区三维总览
- 多个子园区几何模型
- 危险品报警园区红色围栏高亮
- 点击子园区后镜头进入内部视角
- 点击楼层后只展示当前楼层，其他楼层隐藏
- 左侧子园区列表与 Three.js 场景联动
- 右侧报警详情、人员状态、告警趋势图
- Mock 数据驱动，不包含任何真实公司数据、模型、接口

## 运行方式

当前机器如果没有 pnpm，可以使用 npm：

```bash
npm install
npm run dev
```

如果你安装了 pnpm，也可以：

```bash
pnpm install
pnpm dev
```

建议 Node.js 版本使用 16 或 18 以上。当前项目依赖已尽量兼容 Node 14，但新机器建议直接安装 Node 18 LTS。

## 简历描述

基于 Vue3 + TypeScript + Three.js + ECharts 实现工业园区人员定位安全监管三维大屏，使用 Mock 数据模拟人员进入危险品区域触发报警。通过 Raycaster 实现子园区、楼层对象点击拾取，结合 GSAP 完成镜头钻取动画，并通过对象分组与材质控制实现报警园区红色围栏高亮、楼层剖切显隐、报警详情联动展示等交互能力。
